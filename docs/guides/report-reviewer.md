# Report reviewer guide

**Approvals → Review** lists draft reports and those in review. Open one to see a live preview, exactly as it will print.

1. **Submit for review** to take it up.
2. Check it against the results, the sample details and any deviations.
3. Then choose one:
   - **Pass review** sends it to the signatory. Your name prints as reviewer.
   - **Reject** needs a reason and a choice:
     - **Correct the report:** it returns to draft, and you can fix remarks, sample description, customer reference or kind attention.
     - **Send tests back for re-testing:** tick the tests. They return to the analyst, and the report waits until they are approved again, then refreshes with the new results.

Every rejection stays in the history.

You and the signatory must be different people for each report.
